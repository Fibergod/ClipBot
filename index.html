Clip Bot

Clip Bot is a private tool that runs on its owner's own computer. It turns livestreams of streamers who run official clipping campaigns into short, credited highlight clips and uploads them to the owner's own YouTube channel using the YouTube Data API.

What it does

  • Finds new GTA 6 livestream recordings from streamers whose clipping campaigns we have joined (permission to clip).
  • Finds highlight moments, cuts them into vertical Shorts with captions, and credits the streamer with a link to the original stream.
  • Uploads the clips to the owner's YouTube channel and schedules when they go public (YouTube Data API videos.insert).
  • Reads the channel's own video statistics and YouTube Analytics to learn which clips perform best (read-only).

Who can use it

Only the channel owner. Clip Bot is not offered to the public, has no user accounts and no website login. It only ever accesses the single YouTube channel its owner authorizes.
