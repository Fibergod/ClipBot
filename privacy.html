Privacy Policy

Last updated: November 23, 2026

Clip Bot ("the app") is a private tool used only by its owner to upload highlight clips to the owner's own YouTube channel. This policy explains what data the app accesses and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • Google account authorization (OAuth token) for the owner's channel, with these permissions: upload videos (youtube.upload), read the channel's own video information (youtube.readonly) and read the channel's own YouTube Analytics (yt-analytics.readonly).
  • The channel's own video statistics (views, likes, comments, average percentage watched) for videos the app uploaded.

The app does not access other users' data, comments, subscribers' personal information, or any channel other than the owner's.

How the data is used

  • The OAuth token is used only to upload the owner's clips and to read the performance of those clips.
  • Performance numbers are used to decide which kinds of clips to make next (for example which streamers and title styles perform best). A short summary of clip titles and numbers may be sent to Anthropic's Claude API to produce that analysis; no Google account credentials or personal information are sent.

Storage, sharing and retention

  • All data, including the OAuth token, is stored only on the owner's own computer. There is no server and no database operated by the app.
  • Data is not sold, rented or shared with third parties, and is not used for advertising.
  • Video statistics are kept for up to 60 days for analysis and then refreshed or deleted. Deleting the app folder deletes all stored data.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google security settings page). After revoking, the app can no longer access the channel.
